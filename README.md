# Aetheria: Echoes of the Five Elements
Game pixel Neo-Retro. Alur: `index.html` (menu) → `karakter.html` (pilih karakter) → `game.html` (pertarungan).
Tanpa server/build: unggah semua file ke GitHub lalu aktifkan GitHub Pages (Settings → Pages → branch main).
Kontrol: WASD/geser layar = gerak, Shift = lari, Spasi = serang, 1–5 = skill, G = tameng (Valdrik).
